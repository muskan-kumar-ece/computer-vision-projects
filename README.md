## 🔍 Purpose

The purpose of this repository is to:
- Apply computer vision concepts to real-world traffic video
- Explore different approaches for lane change analysis
- Build clear, reproducible demo-level pipelines
- Document learning through structured code and explanations

All work here is part of **academic learning and experimentation**.

---

## 🧪 Projects

### 1. Lane Change Violation Detection using Computer Vision
A demo-level project that detects unsafe lane change behavior by combining:
- Vehicle detection and tracking
- Turn indicator recognition
- Lane change identification based on signaling and motion cues

This project focuses on **indicator-aware lane change detection**.

---

### 2. Lane Change Motion Analysis using Vehicle Trajectories
A complementary project that analyzes lane change behavior using:
- Vehicle trajectory extraction
- Centroid-based motion analysis
- Lateral movement patterns across video frames

This project focuses on **trajectory-based lane change analysis without indicator cues**.
